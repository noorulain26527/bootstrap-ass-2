# Bootstrap Website

A responsive website built using Bootstrap, HTML5, and CSS3. This project was created to practice Bootstrap components and understand how to build a structured and responsive webpage using a CSS framework.

## 🚀 Features

- Responsive Bootstrap Navbar
- Hero Section
- Bootstrap Cards
- Image Carousel / Slider
- Buttons
- Responsive Grid Layout
- Bootstrap Utility Classes
- Clean and Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
